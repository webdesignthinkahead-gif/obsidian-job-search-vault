# Job Search Vault Lite

A free, minimal application tracker for Obsidian: every application in one note, a live pipeline and a list of follow-ups that are due.

## Setup
1. Open this folder in Obsidian (**Open folder as vault**).
2. Install and enable the community plugin **Dataview**.
3. Enable the core plugin **Templates**: template folder `Templates`, date format `YYYY-MM-DD`.
4. Open **01 Dashboard**.

New application: create a note in `Applications` and insert the *Application* template.

Full version with interview prep, STAR stories, weekly reviews and 5 practical guides: https://gumroad.com

*Plain Markdown, your data stays local. Free to use.*
